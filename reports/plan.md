# Implementation and publication plan

1. Publish reviews, the preregistration and the run matrix as a public versioned protocol.
2. Implement algebra, independent sensor generation, paired scene data, full geometric model, lighter controls, the pixel and superpixel benchmarks. Push code, tests, paper draft and site before running models.
3. Check all basis products, gradients, spatial symmetries, split integrity, restart and inference. Train and evaluate the excluded pilot. Preserve faults and empirical diagnoses.
4. Freeze confirmatory models, collect paired outcomes, evaluate external tasks and sensitivity with the disclosed compute budget.
5. Export machine-derived tables, figures, prediction examples, study paper and interactive explorer. Publish artifacts to GitHub and one Hugging Face collection at each milestone. Keep a chronological experiment record, review findings and explicitly mark incomplete contrasts.
