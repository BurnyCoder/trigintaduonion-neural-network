# Preregistration · 26 November 2026

Protocol version 1. The first public Git commit containing this document precedes any model evaluation in this project. Amendments are dated separately and never overwrite the historical decision rule.

**Question.** Does matching a constrained neural sensor encoder to a physical observation rule improve end-to-end classification of a relationship between two spatially selected objects?

**Data.** Draw two beacons, four landmarks and eight objects in the unit square. Require distinct nearest landmark and nearest object for the two beacons and positive nearest-neighbor distance margins. Assign four objects to each latent binary type. For each object draw x from a 32-dimensional standard Gaussian and a coordinate k independently. Draw one pure-imaginary unit filter w per world, half its squared energy in each half of the basis. Observe z = b (w ⋆ x)[k] + ε with Gaussian noise of standard deviation 0.1. The label is whether the selected objects have equal b. Swap a selected object and an opposite-type unselected object's entire reading to make the opposite-label mate. The classroom analogy is two people each finding their nearest signpost and then the nearest parcel. The question is whether the two parcels have the same kind of contents.

**Intervention.** C is canonical CD32. R reverses six ordered products on a uniformly chosen half of the unordered imaginary basis triples touching coordinates 16–31. Both rules have identical support, identity and imaginary squares. The fixed lower 16-component algebra is shared. Re-render the same latent scenes, noise, filter and coordinate queries under C and R. Each learner sees positions, visible roles, x, k and z. Training receives scene labels only. The independent rendering table comes from the scalar oracle. The implementation uses real signed weight tying. [Cayley–Dickson convention](https://arxiv.org/pdf/math/0511691) · [Basis triples](https://arxiv.org/pdf/1405.6888)

**Splits.** The unit of allocation is a parent scene and both mates. Use disjoint random streams for splits, filter, rule and initialization. Replicates 0–7 each get a new world and training initialization. Seed 42 is a development pilot excluded from confirmation. Per primary replicate use 1,024 training families, 256 validation families and 1,024 test families. Withhold output coordinates 12–15 and 28–31 from training. Secondary tests use these eight channels and a fresh 16-object population. Original held-out task uses training-supported channels and eight objects. Freeze model choices and confirmatory checkpoints before inspecting confirmatory test outcomes.

**Neural learning.** Fit a shared sensor bank followed by a nonlinear encoder, two fully connected role-to-role distance-attention/residual message blocks and a symmetric readout of the beacon embeddings. All stages in the full model receive gradients from scene BCE. The one-hop control cannot send object readings through a landmark to a beacon in one round. The shallow coordinate-aware set model sees all entities. A frozen random encoder retains a trainable readout. Select the stronger shallow control using validation accuracy separately per seed/rule. Geometry-only and multiset-only decisions are identical on the two mates, giving exactly one correct binary decision per family.

**Decisions.** Let A(m,t) be the mean accuracy on both mates, averaged over test families in one world. Use two-sided paired Student intervals at 95% across the eight independent worlds, never treating pixels, objects or mates as independent replicates. Report raw points, effect sizes in percentage points, and the fraction of complete families with both answers correct. Require lower confidence bounds above 60% for matched-model task success. Claim algebra matching only when both lower bounds exceed +1 point for A(C,C)−A(R,C) and A(R,R)−A(C,R). A bound entirely below +1 rules out a gain of that size for that direction under this protocol. Require positive lower bounds for the full CD32 network versus both the frozen encoder and validation-selected shallow control on C observations before attributing benefit to learned multistage processing. Missing worlds preclude confirmatory decisions. Natural-image transfer separately requires a +1-point lower bound on ciFAIR-10. All other contrasts are descriptive. Negative results, computation failures and post-hoc changes are retained.

**Defaults.** Scene models use AdamW, initial learning rate 0.003, weight decay 0.0001, 80 epochs, 128 scenes per minibatch, cosine decay, highest validation accuracy with earliest tie. Pair the four fits on data order and coefficient initialization where dimensions agree. Validation-only pilot repairs must be published before confirmation. Crossed arms share all training settings. Seed and sample-size sensitivity, rotated/reordered inputs, algebra baselines and external benchmarks are in the [run matrix](planned-runs.md).
