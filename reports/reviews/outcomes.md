# Outcome review

The registered crossover is complete. Reversing the observation rule reversed which of two identically sized neural networks generalized to fresh scenes. The matched cases also retained accuracy on the withheld sensor channels and on scenes with more candidate objects. This is a controlled intervention in a simulator with an encoded channel relationship. The learned quantity under test is a spatial relation between two latent object types. A model trained in one world is evaluated on fresh families in that world. [Eight-world crossover and distribution shifts](https://github.com/BurnyCoder/trigintaduonion-neural-network/blob/1f0fba5/reports/summary.md)

The unit of replication is a world. Each world changes the hidden filter, randomized table and training seed. Treating the two mates, individual objects, or individual model decisions as independent replicates would underestimate uncertainty. An independent recount reconstructs family accuracy and classification accuracy from individual decisions. The fit and evaluation manifests establish that all registered primary and control checkpoints were fixed before opening the first confirmatory test outcomes. [Recount](../../results/recount.json) · [Decision rule](../preregistration.md)

The one-hop network has no path from object payload to decision. Its output is constant because every landmark input is zero and the intervening updates are bias-free. The validation-selected global set control and frozen encoder provide additional comparisons. In the full network the multiplication rule changes in the sensor and both downstream message blocks together. This experiment identifies the effect of matching the rule throughout that architecture. It leaves the stage responsible for the gain unresolved. The attention initialization already favors nearby neighbors. [Implementation](../../src/trig32/models.py) · [Ablation definitions](../planned-runs.md)

The global set comparator sees every entity, but also has a different sensor encoder. Even a positive contrast with both depth controls would establish the advantage of the full learned processing chain over those implementations. Isolating the marginal contribution of the second geometric hop requires another comparison that keeps the sensor representation and the information available to the readout fixed. The privileged control's expected accuracy follows from the sensor's Gaussian noise and the two independent selected objects. The randomized intervention preserves the marginal signal and noise at every channel. In the pilot, changing which object occupied a given position disrupted predictions, while rigid transformations and within-role reindexing preserved all binary decisions.
